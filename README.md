📌 Project Overview

This project presents an interactive Mobile Sales Data Analysis Dashboard created using Microsoft Power BI.

The dashboard helps analyze mobile sales performance and provides meaningful insights through interactive visualizations, KPI cards, filters, and sales analysis.

🛠 Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Visualization
* Data Analysis

## 📈 Dashboard Features

* Sales KPI Analysis
* Quantity Analysis
* Transaction Analysis
* Average Sales Analysis
* Product/Model Analysis
* Region-wise Analysis
* Sales Trend Analysis
* Interactive Filters and Slicers

## 📌 Key Insights

* Analyzed overall mobile sales performance.
* Compared sales across different products/models.
* Analyzed sales trends and transaction patterns.
* Evaluated quantity sold and average sales.
* Identified important sales performance trends using interactive filters.
